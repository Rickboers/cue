# Changelog

All notable changes are listed here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and versions follow [semantic versioning](https://semver.org).

## [1.0.0] - 2026-11-09

### Added

- First public release.
- A teleprompter that floats over the Camera app, upright or landscape.
- Voice following that forgives misheard, skipped and repeated words, with on-device speech recognition only.
- Tilt and Constant scrolling.
- Voice commands: go back, back two lines, skip ahead, next sentence, back to the top, pause and resume, next and previous point.
- Talking points that light up as you talk about them.
- A script library, and settings for text size, margins, line spacing, the current line and darkening spoken words.
- README, AGENTS.md for AI coding tools, privacy notes, an MIT license and a CI check.
